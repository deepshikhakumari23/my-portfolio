# My Professional Portfolio 🚀

Welcome to the repository for my personal portfolio website, live at [my-portfolio-nine-sigma-51.vercel.app](https://my-portfolio-nine-sigma-51.vercel.app/). 

This project serves as a digital hub showcasing my academic research, technical expertise, and engineering projects spanning embedded systems, digital twin architectures, and full-stack software pipelines.

## 🌟 Features

- **Responsive Design:** Fully optimized for desktops, tablets, and mobile devices.

## 📂 Key Projects Showcased on the Site

1. **DRONA:** An EdTech AI pipeline utilizing K-Means Clustering to segment user behavioral data, simulating over 150k+ activity rows and 5,000 user cohorts.
2. **NASA-BMS-HIL Framework:** A digital twin system for Battery Management state estimation, streaming NASA PCoE battery aging datasets to an STM32 controller for real-time fault detection.
3. **Automated HIL Tester:** A hardware-in-the-loop validation suite designed to stress-test UART communication links between STM32 and Python with sub-millisecond jitter verification.
4. **VerifierVerilog:** A custom engine integrated with Icarus Verilog for RTL simulation, focusing on Adaptive FinFET Doping for space-grade processor optimization.
